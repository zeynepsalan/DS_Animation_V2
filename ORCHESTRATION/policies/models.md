# Model politikası

[Kaynak karar](../../DECISIONS/orchestration/DEC-0028-models.md): yalnız Codex worker; kullanıcı havuzu `gpt-6.1-sol`, `gpt-6.1-terra`, `gpt-6-luna`. Göreve göre esnek seçilir, erişim gerçek çalıştırmada doğrulanır; sessiz model değişimi veya kısıt dışı fallback yapılmaz. Cost token tüketimidir; sert limit ve hız hedefi belirlenmedi, kalite önceliklidir. Ölçülmeyen tasarruf rakamı uydurulmaz. Görsel aracı worker modeli değildir.
