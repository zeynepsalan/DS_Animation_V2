# DEC-0035 — Production deploy için ayrı onay

Durum: Kabul edildi. Kapsam: orkestrasyon ve yayın yetkisi. Karar tarihi: 2026-11-14; kayda alınma tarihi: 2026-11-14.

Kaynak: Canlı yerel form `2026-11-14-v2`, gönderim ID `3277a486-8930-4d36-815a-639a9bf50ce7`, soru 1, seçenek 1. Yönetici otomatik açılan yeni turda yanıtı okudu. Özel runtime yanıt dosyası Git'e alınmaz; burada yalnız bu kararı izlemeye yetecek kaynak bilgisi kaydedilir.

Seçilen seçenek: “GitHub push otomatik; production deploy için ayrıca benim onayım alınsın.”

Karar: Mevcut anlamlı ve doğrulanmış normal GitHub push yetkisi korunur. Her production deploy için ayrıca kullanıcının onayı gerekir. Bu karar kendi başına herhangi bir deploy için onay değildir.

Gerekçe: Kullanıcı belirtmedi. Yerine aldığı ilgili hüküm: [DEC-0030](../README.md#dec-0030) içindeki production deploy kararının açık olması; ürün/mimari/bütçe ve Git push hükümleri korunur. Uygulama ve doğrulama: Canlı v2 gönderimi queue ile yönetici turunu açtı ve yönetici yanıtı okudu; production deploy yapılmadı.
