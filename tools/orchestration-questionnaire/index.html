1. Production deploy yetkisi nasıl olsun?

GitHub push: kodu GitHub’a gönderir. Production deploy: uygulamanın kullanıcıların eriştiği canlı sürümünü yayınlar.

Önceden kararlaştırıldı: yalnız yönetici worker açar. Yönetici bağımlılık ve riske göre ayrı worktree veya ortak çalışma alanı seçer.
